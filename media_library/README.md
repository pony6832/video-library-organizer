# 影像圖書館（媒體清冊檢視面板）

匯入 Video Library Organizer 0.3.0 產生的「媒體清冊」Excel，就能像影像圖書館的總目錄一樣瀏覽、搜尋、挑選和播放影片。

## 需求
- Windows + Python 3.9 以上
- ffmpeg / ffprobe（用來產生縮圖、預覽格、代理檔，並讀取時長和解析度；本機已安裝 winget 版）
- 這台電腦要能讀到清冊中的影片路徑（例如 `\\192.168.1.10\...`）

## 啟動
1. 雙擊 **`啟動影像圖書館.bat`**（第一次會自動安裝套件），瀏覽器會開啟 `http://127.0.0.1:8765/`
2. 點「匯入清冊」，或直接把 `xxx_媒體清冊.xlsx` 拖曳到網頁上
3. 若要讓同事在區網連線，改用 **`啟動影像圖書館_區網分享.bat`**，對方開啟 `http://你的IP:8765/`

也可以用指令列：`python server.py --import "1028女神林襄_媒體清冊.xlsx" --open`

## 功能
**總目錄**
- 格狀檢視：縮圖、時長、狀態、檔名、資料夾、內容描述、關鍵字；滑鼠在縮圖上左右移動可預覽整段影片
- 清單檢視：Excel 的全部欄位加上技術資訊，點欄位標題可排序
- 全文搜尋（`/` 鍵）：可同時搜尋檔名、描述、重點、關鍵字、路徑、備註，多個詞以空白分隔，結果會標示符合的文字
- 左側篩選：資料夾樹（1機、2機…）、狀態、已挑選、有標記點、檔案可否存取、媒體類型、關鍵字雲
- 可多選（Ctrl／Shift＋點擊或勾選方塊）後批次挑選、改狀態、匯出、播放
- 可匯入多份清冊，會依「完整路徑」合併。重新匯入同一份清冊時只更新 Excel 欄位，你的挑選、評等、備註、標記點都會保留

**播放器**
- 播放／暫停、拖曳進度條（懸停時顯示畫面預覽）、±5 秒／±1 秒、逐格前進後退
- J／K／L 變速（倒轉與 2×、4×、8× 快轉），速度可選 0.25×～8×
- 時間碼 HH:MM:SS:FF 與秒數可切換、音量、靜音、全螢幕、子母畫面
- A-B 區段循環、整段循環、自動播放下一部、上一部／下一部、底部播放清單
- 標記點（按 X）：可加說明，設定 A/B 後會記錄入點→出點，匯出時一併寫入 Excel
- 擷取目前畫面存成 PNG（按 S），記住上次播放位置
- 右側面板依 Excel 原始欄位順序列出全部內容，點關鍵字可直接篩選；另有技術資訊頁（編碼、解析度、位元率…）和 Markdown 頁
- 挑選 ★、1～5 星評等、修改狀態、備註（會自動儲存）、下載原始檔、複製路徑
- 遇到瀏覽器不支援的編碼（例如 XAVC 4:2:2 10-bit），會提示可一鍵產生 H.264 代理檔再播放

按 `?` 可查看全部快捷鍵。

## 編輯欄位，並即時寫回原始 Excel
- **播放器右側「清冊資料」：** 按「✎ 編輯所有欄位」後，每個欄位都能直接修改；也可以把滑鼠移到單一欄位上，按「✎ 編輯」只改那一欄。
  - 一般欄位：按 Enter（多行文字按 Ctrl+Enter）或點到別處就會儲存；按 Esc 取消
  - 關鍵字、重點：以標籤方式編輯。在輸入框打字後按 Enter（或輸入 、 ，）新增，按 ✕ 刪除，雙擊標籤可修改文字，輸入框是空的時候按 Backspace 會刪除最後一個
  - 「＋ 新增欄位」：新增自訂欄位，儲存後會在 Excel 最右邊新增這一欄
- **清單檢視：** 雙擊任一儲存格就能直接修改。
- **批次：** 多選後可以統一加入或移除關鍵字、改狀態。
- **全部關鍵字：** 在左側「關鍵字 → 全部」視窗中，按 ✎ 可重新命名（輸入已存在的關鍵字就會合併），按 ✕ 會從所有媒體刪除該關鍵字。
- **修改紀錄：** 每一次修改都會記錄修改前後的內容，按「還原」即可改回去，也會一併寫回 Excel。

**寫回方式**
- 用「匯入清冊 → 輸入檔案路徑」匯入，或用 `--import` 參數匯入，會自動連結原始檔。用上傳方式匯入時，系統會在桌面、下載、文件中尋找同一份檔案；找不到的話，到左側「已匯入清冊」按「連結原始檔」。
- 只會寫入被修改的儲存格，其他內容和格式維持不變。每份清冊第一次寫入前，會先備份到 `data\backups\`（保留最近 20 份）。
- 上方的狀態標示會顯示同步情況：✓ 已同步／⟳ 寫入中／⚠ 檔案開啟中。
- **Excel 正開著這份清冊時：** 若電腦有安裝 Microsoft Excel，會直接寫入那個已開啟的視窗並存檔。否則修改會先排隊，等你關閉 Excel 後自動寫入，修改不會遺失。
- **在 Excel 裡改了內容：** 面板會提示「Excel 已在外部修改」，到左側按「重新載入」即可套用，並記錄到修改紀錄中。
- 「⚙ 設定 → 寫回 Excel」可以關閉自動寫回，或選擇把挑選、評等、備註也寫進 Excel。

## 路徑對應
如果影片的實際位置和清冊上的路徑不同（例如網路磁碟已對應成 `Z:\`，或檔案搬到其他硬碟），到「⚙ 設定 → 路徑對應」新增一條規則：
`\\192.168.1.10\` → `Z:\`。儲存後會立即重新檢查哪些檔案讀得到。

## 檔案結構
```
server.py         後端（FastAPI）
static/           前端頁面
config.json       設定（路徑對應、ffmpeg 位置、代理檔高度）
data/library.db   資料庫（目錄、挑選、評等、備註、標記點）
data/cache/       縮圖、預覽格、代理檔快取（可放心刪除，需要時會重新產生）
```

## 與 Video Library Organizer 一起使用時
Organizer 批次結束時會從它自己的 SQLite 重建 Excel。如果用面板修改清冊後，又用 Organizer 對同一份清冊重新執行分析，面板寫入的修改可能會被覆蓋。建議等 Organizer 分析完成後再進行編輯；需要時可從 `data\backups\` 取回修改前的備份。
