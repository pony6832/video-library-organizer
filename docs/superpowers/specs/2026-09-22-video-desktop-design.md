# Media Catalog Video Desktop 中文設計

使用者已同意輕量安裝版、首次連網設定、僅辨識影片、最新正式 Gemini 模型，以及持續實作至完成。保留 A+ 舊版，不推送或覆蓋遠端 Release。

## 交付與使用流程

交付 Windows x64 安裝 EXE，安裝後提供獨立程式與桌面捷徑。內含 Python 與核心函式庫，使用者不需安裝 Codex。第一次開啟顯示環境檢查與設定入口；外部工具、本地模型在明確按下設定後下載。顯示下載進度、失敗原因與可重试操作。安裝檔不內含模型權重或 API Key。

主畫面分為三步：選資料夾、選分析模式並開始、開啟成果。顯示影片數、影片容量、完成／總數、未完成、目前影片、進度條與文字狀態。保留一般本地優先及強制 Gemini 兩種模式；強制使用前顯示請求上限與雲端傳輸確認。保留安全停止、同模式續跑、Excel 已審核保護。診斷與環境設定移至次要區域。燈色不是唯一狀態線索。

## 資料與模型

桌面掃描只新增影片；已有資料庫中的圖片不刪除、不重跑，不納入影片工作進度或 Gemini 估算。影片分析仍擷取影格。原始媒體不移動、不修改、不刪除。成果仍在指定根目錄下的媒體整理成果。

Gemini 每次批次啟動查詢官方 models API，以可用、支援 generateContent 的通用 Flash 正式版挑選最高數值版本；不使用 Flash-Lite、Preview、Experimental、Live、TTS 或生成影像模型。不以未保證正式版的 latest 別名替代。查詢結果不是生成成功保證；無權限、配額或格式錯誤明確回報，不退回舊模型。每一批次绑定明確模型 ID 並顯示；紀錄不含 Key。查不到正式模型時保留本地結果並標示雲端未完成，不假稱成功。新發布命名不符合已知安全規則時拒絕猜測，提示更新軟體。

## 先行可靠性修復

1. Worker 不再清除啟動期間收到的安全停止要求。
2. 強制批次續跑時更新目前媒體統計，保留已完成片段及請求紀錄。
3. 各種損壞 XLSX 轉為一致可讀錯誤，保留原檔。
4. 舊安裝器中途失敗還原可用舊版，失敗目錄與備份保留，不遞迴刪除使用者資料。

## 包裝與驗收

使用 PyInstaller 封裝，frozen EXE 以專用參數派送清冊／worker，避免遞迴啟動 GUI。使用 Inno Setup 建立每使用者安裝包，與 A+ 舊捷徑分開。卸載只移除安裝檔，不刪媒體與分析成果。未取得簽章憑證時清楚標示未簽章，不宣稱 Windows 信任或免警告。

回歸測試涵蓋停止競態、續跑新增檔案、損壞 Excel、安裝還原、混合資料夾只分析影片、模型清單分頁及排除預覽版。最後執行完整測試、實際 EXE 啟動與隔離目的地安裝。付費 Gemini 測試不預設執行；未能驗證的乾淨機器條件與簽章狀態寫入交付說明。
